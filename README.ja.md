# HomePodCast

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語**

Windows PC の音声を AirPlay 2 で HomePod にリアルタイム送信します。ゲームや動画視聴のための低遅延ツールです。

HomePod ソフトウェア 27 では TuneBlade から音が出なくなりました。HomePodCast は C# でゼロから実装したネイティブ版で、約 350 KB の exe ひとつで動き、仮想サウンドカードも要りません。

## 実測値

| 条件 | 値 |
| --- | --- |
| 映像に対する音の遅れ（遅延 120 ms 設定、スマホの 60 fps 動画で実測） | 156 ms |
| 映像に対する音の遅れ（遅延 105 ms 設定、推定） | 約 141 ms |
| 送信統計（音切れ／送信遅れ／再送） | 0 / 0 / 0 |
| メモリ（プライベート） | 約 28 MB |

## テスト環境

HomePodCast は個人プロジェクトで、実機テストは次の 1 組だけです。

- スピーカー：HomePod（第2世代）1 台、HomePod ソフトウェア 27.0（24J361）、Wi‑Fi 接続
- PC：Windows 11 PC 1 台（既定の出力は仮想サウンドカード）

実機では未テストのもの：

- HomePod mini、HomePod（第1世代）、Apple TV、他社製の AirPlay スピーカー
- **ステレオペアとマルチルーム**：プロトコルの調査に基づいて実装し、シミュレートしたスピーカーでのみテスト
- 物理的なサウンドカードやヘッドセット、ほかの Windows バージョン、PC が有線か Wi‑Fi かによる違い

ほかの機器で試した場合は、機種、ソフトウェアのバージョン、音切れせずに使える最小の遅延設定、ログ（`homepodcast.log`。「設定 → ツール → ログ → ログ フォルダーを開く」で表示できます。場所は `%APPDATA%\HomePodCast`、Microsoft Store 版は `%LOCALAPPDATA%\Packages\qiyinxi.HomePodCast_21rkx5qfj0b6t\LocalCache\Roaming\HomePodCast`）を添えて issue でお知らせください。

## 機能

- AirPlay 2 リアルタイム音声：一時ペアリング、全区間暗号化。遅延は 100〜500 ms の範囲で 1 ms 単位に調整可能
- 1 つのウィンドウにホーム・ミキサー・マイクとエフェクト・設定。Windows のライト／ダーク モードに追従
- シーン：おすすめ（120 ms、既定）・ゲーム（105 ms）・音楽（500 ms、最も安定）・映画（200 ms、ブラウザー拡張機能やプレーヤーの音声遅延設定と連携）・カスタム
- タスクトレイ常駐：スピーカーを自動で見つけて自動再接続し、スリープから復帰すると再開。他のデバイスにスピーカーを使われたときは取り返さない
- 他のデバイスを黙って切断しない：iPhone や Mac が HomePod に送信しているときは、「接続」を押すと先に確認し、自動接続はスピーカーが空くまで待つ（そのスピーカーに切り替える再生プロファイルを適用したときも同じ）
- Apple TV のホームシアター：Apple TV のスピーカーに設定した HomePod（Apple TV は使っていないときも接続したまま）は、HomePodCast の接続中だけ一時的に引き継ぎます。ペアリングコードは不要で、切断後は Apple TV が次に再生するときに再び接続します。「設定」で先に確認するようにもできます
- トレイアイコンを右クリックするとクイックパネル：音量とミュート、シーン、ナイトモード、マイク、接続・切断
- ミキサー：アプリごとの音量・ミュート・レベルメーター。アプリ別ルーティング（HomePod／この PC／両方）や、キャプチャする出力デバイスを選ぶサウンドカード別ルーティングも可能（後述）
- 音量の上限、ナイトモード（ダイナミックレンジ圧縮＋低音カット）、グローバルショートカット。キーボードの音量キーでも HomePod を調整可能（Windows の音量に連動、または送信中は HomePod だけを操作。後述）
- マイクを HomePod へ（リバーブとイコライザー付き）、ヘッドホンで低遅延モニター。スピーカーに送るすべての音にイコライザーのプリセット
- ステレオペアとマルチルーム同期（実験的、実機では未検証）
- Apple TV：初回だけ「接続」でテレビとペアリング（テレビに表示される 4 桁の数字を入力）。ホームシアターのスピーカーが HomePod なら HomePod から音が出ます（実験的、実機の Apple TV では未検証）
- 音ズレ測定：画面のフラッシュと「カチッ」という音で、音が映像よりどれだけ遅れているかがすぐわかる
- 設定のスピーカー情報：モデル、システムと AirPlay のバージョン、IP アドレス、Wi‑Fi MAC アドレス（ルーターの接続機器一覧でこれを手がかりに HomePod を探し、周波数帯の確認や固定 IP の割り当てに使える）、Bluetooth アドレス、デバイス ID
- ブラウザー拡張機能（ベータ）：YouTube や bilibili の映像を遅らせて HomePod の音に合わせる。「音楽」シーンの 500 ms は音楽を聴くためのもので、動画は「映画」か「おすすめ」がいちばん滑らか（映像の遅延が 300 ms を超えると拡張機能のポップアップでこれを案内）
- 更新の確認（既定では自動確認なし、[アップデート](#アップデート)を参照）。MSI 版は SHA-256 を検証したうえでワンクリックで更新
- 英語・簡体字中国語・繁体字中国語・日本語の UI

再生プロファイル、スピーカーと音源ごとの実測補正、アプリ別の HomePod 独立音量、個人情報を除去した診断レポート、ブラウザーの「同期フルスクリーン」と ±5／±20 ms 調整にも対応しています。操作と制限は[プロファイル・補正・診断（英語／簡体字中国語）](docs/PLAYBACK_FEATURES.md)をご覧ください。ブラウザー拡張機能のサイト別補正は実測補正に上乗せされます。サイトごとに補正済みの場合は、実測補正のあとでサイト別補正をリセットしてください。

## 使い方

1. [.NET 10 デスクトップ ランタイム](https://dotnet.microsoft.com/download/dotnet/10.0)（x64）をインストールします。
2. [Releases](https://github.com/qiyinxi/HomePodCast/releases) から HomePodCast をダウンロードします。パッケージは 2 種類あります。
   - **インストーラー（推奨）`HomePodCast-<バージョン>-x64.msi`**：インストール先を選べます（既定は `C:\Program Files\HomePodCast`）。スタート メニューのショートカットと必要なファイアウォール規則が自動で追加されます。アップグレードは新しい MSI を実行するだけです。アンインストールは「設定 → アプリ」から行います。「Windows 起動時に自動起動」をオンにしていた場合は、先にアプリでオフにしてください。
   - **ポータブル版 `HomePodCast-<バージョン>-win-x64.zip`**：任意の場所に展開して `HomePodCast.exe` を起動します。初回はファイアウォール規則の追加を求められます。

   ファイアウォール規則はローカル ネットワークのみを許可し、プライベート ネットワークでのみ有効です。HomePod が時刻同期と再送要求のために PC へ接続してくるため必要です。Windows がネットワークをパブリック ネットワークに分類している場合（Wi-Fi から有線 LAN に切り替えた後など）は規則が適用されません。HomePodCast がそれを知らせて Windows の設定を開けるので、「ネットワーク プロファイルの種類」を「プライベート ネットワーク」に変更してください（信頼できる自宅のネットワークの場合のみ）。どちらのパッケージも設定とログは `%APPDATA%\HomePodCast` に保存されます。Microsoft Store 版が書き込むファイルはアプリ専用の保存場所 `%LOCALAPPDATA%\Packages\qiyinxi.HomePodCast_21rkx5qfj0b6t\LocalCache\Roaming\HomePodCast` に置かれ、アンインストール時に Windows が削除します。どの版でも「設定 → ツール → ログ → ログ フォルダーを開く」で正しいフォルダーが開きます。
3. HomePod が自動で見つかり、接続されます。音声はシステム音量より前の段階で取り込むので、Windows の音量で送信する音が変わることはありません。HomePod には独自の音量がありますが、既定では Windows の音量がそのまま HomePod の音量になります。両方は常にそろい（接続時は小さいほうに合わせます）、Windows をミュートすると HomePod もミュートされます。既定の出力が PC のスピーカーで、HomePod だけで聴きたい場合は、「設定 → キーボードの音量キー」で「送信中は HomePod を操作」を選び、Windows をミュートしてください（[キーボードの音量キー](#キーボードの音量キー)を参照）。

表示言語は Windows の表示言語に従います（翻訳のない言語の場合は英語）。変更するには、設定ページの「言語 / Language」を使うか、`%APPDATA%\HomePodCast\config.json` の `"Language"` を言語コード（`"zh-CN"`、または `src/i18n` のファイル名。例：`"ja"`、`"en"`、`"de"`）か `"auto"` にします。

コマンドライン（トラブルシューティング用）：

```
HomePodCast.exe scan                         ローカル ネットワーク上の AirPlay スピーカーを一覧表示
HomePodCast.exe stream --host <IP> --latency 120 --seconds 30
HomePodCast.exe mutetest                     ミュート中も音声を取り込めるか確認
```

## すべて送信とアプリ別ルーティング

既定では、HomePodCast は PC のサウンド出力全体をキャプチャして、すべて HomePod に送ります。この経路自体は遅延を増やさないので、ゲームにはこちらを使ってください。PC 自体のスピーカーから音が出るかどうかは Windows の音量で決まります。HomePod だけで再生するには、「設定 → キーボードの音量キー」で「送信中は HomePod を操作」（または「Windows のミュート中のみ」）を選び、Windows をミュートします。既定の「HomePod を Windows の音量に連動」では、Windows をミュートすると HomePod もミュートされます。

アプリ別ルーティングでは、アプリごとに送信先を HomePod・この PC・両方から選べます（ミキサー ページで設定）。たとえばゲームの音は HomePod に、ボイスチャットはヘッドセットに残す、といった使い方です。ただし遅延が増えます。

| | すべて送信（既定） | アプリ別ルーティング |
| --- | --- | --- |
| 有効になる条件 | ルーティングを使っていないとき | いずれかのアプリに個別の送信先を設定したとき、または既定が「この PC」のとき |
| 音のキャプチャ方法 | 出力全体をまとめて | アプリごと（Windows のプロセス ループバック） |
| HomePod への追加遅延 | なし | 約 35 ms（再生から送信までの実測：21 ms 対 55 ms） |
| Web 動画の音ズレ補正（ブラウザー拡張機能） | 自動補正 | 自動補正（追加の 35 ms も含む） |
| ゲーム | 遅延が最小 | 35 ms 遅れ、補正できない |
| 「HomePod」に設定したアプリ | — | この PC では消音、Windows の音量ミキサーでは 0% と表示 |
| システム音 | Windows の音量に従う | この PC だけで再生 |
| 必要な環境 | Windows 10/11 | Windows 10 バージョン 2004 以降 |

初めてルーティングを有効にするときは確認ダイアログが表示されます。すべてのアプリを「既定」に戻し、既定を HomePod にすると、すべて送信に戻ります。ルーティング中に HomePodCast が強制終了された場合、「HomePod」に設定したアプリは再び起動するまで 0% のままです。

### サウンドカード別ルーティング（キャプチャ デバイス）

「ミキサー → キャプチャ デバイス」で、どの出力デバイスの音を送るかを選びます。既定では Windows の既定の出力に従います。自分では聞かないデバイスを選び、Windows のアプリの音量設定（ミキサー ページのボタンから開けます）またはアプリ自身の設定で、HomePod に送りたいアプリ（ゲームなど）の出力先をそのデバイスにします。ボイスチャットなど他のアプリはいつもどおりヘッドホンで再生されます。デバイス全体をまとめてキャプチャするので、すべて送信と同じく追加の遅延はなく、アプリ別ルーティングのように約 35 ms 遅れることはありません。

- 空いているサウンドカードか仮想サウンドカードが必要です（VB-CABLE、NetEase UU の仮想サウンドカード、Steam Streaming Speakers、スピーカーのない HDMI モニターなど）。仮想サウンドカードは Microsoft の署名が必要なカーネル ドライバーなので、HomePodCast からはインストールできません。
- 起動時にしか出力デバイスを選ばないゲームもあります。変更後はゲームを再起動してください。
- 選んだデバイスが取り外し・無効化・アンインストールされても、既定の出力には切り替えません（ヘッドホンのボイスチャットがスピーカーに流れないように）。キャプチャを止めてホーム ページに表示し、デバイスが戻ると自動で再開します。
- アプリ別ルーティングと組み合わせることもでき、そのルールはこのデバイスで再生しているアプリに適用されます。
- キャプチャ デバイスを選んでいるときは、「HomePod を Windows の音量に連動」はそのデバイスの音量に連動します。音量キーが変えるのは Windows の既定の出力だけです。音量キーで HomePod を調整したい場合は、そのデバイスを既定の出力にしてください。
- 送信中、マイクの「この PC でモニター」がキャプチャ中のデバイスを使っている場合（たとえば両方とも既定の出力に従う場合）はモニターを一時停止します。そうしないと声が HomePod に 2 回届きます。

## キーボードの音量キー

「設定 → キーボードの音量キー」で、音量＋・−・ミュートの各キーが HomePod にどう働くかを選べます。

- **HomePod を Windows の音量に連動**（既定）：送信中は Windows の音量がそのまま HomePod の音量になります。Windows の 0〜100% が HomePod の 0〜音量の上限に対応し、キーや Windows の音量スライダーで HomePod が変わり、このアプリで HomePod を調整すると Windows も変わります。接続時と音量の上限を変えたときは両方を小さいほうに合わせるので、どちらも勝手に大きくなりません。Windows をミュートすると HomePod もミュートされます。
- **送信中は HomePod を操作**：送信中はこの 3 つのキーで HomePod だけを調整し（1 回 2%）、Windows の音量は変わりません。画面下部に HomePod の音量が表示されます（排他フルスクリーンのゲームでは表示しません）。送信していないときは通常どおり Windows を調整します。既定の出力が PC のスピーカーで、HomePod だけで聴きたい場合に向いています。Windows をミュートしてから、キーで HomePod を調整してください。
- **Windows のミュート中のみ**：以前の動作です。Windows がミュートまたは音量 0 のときだけキー操作を HomePod に送り、Windows はミュートのままにします。
- **オフ**：キーは Windows だけを調整します。

PC に使用できる出力デバイスがない場合（サウンド ドライバーがない、デバイスが無効または取り外されている）、「HomePod を Windows の音量に連動」と「Windows のミュート中のみ」でも、デバイスが戻るまでは送信中にキーで HomePod を直接操作します。管理者として実行しているアプリが前面にあるときや、リモコン・マウスのソフトウェアがキーではなくメディア コマンドを送る場合は、キーで Windows の音量が変わります。その場合は「HomePod を Windows の音量に連動」なら HomePod も追従します。

## アップデート

HomePodCast は、このリポジトリの GitHub Releases で新しいバージョンを確認できます：「設定」→「ソフトウェア更新」→「更新を確認」。これはローカル ネットワークの外へ送る唯一のリクエストで、求められたときにしか送りません。**自動確認は既定でオフ**です。「更新を自動で確認」をオンにすると、起動の約 30 秒後と、その後 24 時間ごとに確認します（開発版は自動では確認しません）。リクエストは `api.github.com/repos/qiyinxi/HomePodCast/releases` への HTTPS GET 1 回だけで、User-Agent は `HomePodCast/<バージョン>` です。アカウントは不要で、PC やスピーカーの情報は一切送りません。リクエストのたびにログに記録します。

- **更新チャネル**：正式版では正式版だけを、ベータ版ではベータ版も案内し、いちばん新しいものを案内します。使用中のベータ版が最新の正式版より新しい場合は、次の正式版まで待ちます（ダウングレードはしません）。
- 自動確認で新しいバージョンが見つかると、通知を 1 回表示し、ホームに「更新」「リリースノート」「このバージョンをスキップ」付きのバナーを出します。手動で確認した結果は設定に表示します。
- **クリックしない限りインストールしません。** MSI でインストールした場合、「更新」を押すと確認のうえ新しい MSI をダウンロードし、GitHub がそのファイルに公開している SHA-256 で検証します（一致しない場合や SHA-256 がない場合は削除し、何もインストールしません）。その後 HomePodCast を終了し（送信は 1 分ほど止まります）、インストーラーを実行します。このとき Windows が管理者の承認を求めます。完了すると HomePodCast が自動で再起動し、更新後のバージョンを知らせます。承認を拒否した場合は、元のバージョンが再起動します。
- ポータブル版（zip）は自動では更新されません。「更新」でリリースページが開きます。
- Microsoft Store 版は Store から更新され、アプリ自身が GitHub に問い合わせることはありません。

## よくある質問

### ときどき音が途切れる

**原因**：音は PC → ルーター → HomePod と 2 区間の無線を通ります。HomePod（第 2 世代）は Wi‑Fi 4（802.11n）にしか対応しておらず、人が通ったり腕を上げたりするだけでも、壁や棚の扉と同じように電波がさえぎられ、ときどきパケットが遅れたり失われたりします。遅延 120 ms（「おすすめ」）では HomePod 自身の処理に約 85 ms かかり、ネットワークの揺らぎと再送に使えるのは約 35 ms だけです。これを超える揺らぎが 1 回あると、音が 1 回途切れます。

**対策（この順に試してください）**：

1. PC はできれば有線 LAN でつなぐ：無線が 1 区間だけになります。
2. Windows のワイヤレス アダプターの省電力：コントロール パネル → 電源オプション → プラン設定の変更 → 詳細な電源設定の変更 →「ワイヤレス アダプターの設定 → 省電力モード」を、バッテリ駆動と電源に接続の両方で「最大パフォーマンス」にします。
3. デバイス マネージャー → ネットワーク アダプター → 無線アダプター → プロパティ →「詳細設定」：「ローミングの積極性」（Roaming Aggressiveness）を最低にします。項目があれば「MIMO 省電力モード」（MIMO Power Save Mode）を「SMPS なし」（No SMPS）に、「パケットの結合」（Packet Coalescing）を無効にします。名前はアダプターによって異なります。
4. HomePod の周波数帯：HomePod（第 2 世代）は 2.4GHz 帯と 5GHz 帯を使えますが、ルーターが 2 つの帯域を同じ名前で出していると（バンドステアリング、Smart Connect）、2.4GHz 帯につながることがあります。近くに Wi‑Fi が多い場所では 2.4GHz 帯は混み合っています。5GHz 帯に別の名前を付け（Smart Connect をオフ）、iPhone をそこにつなぎ、「ホーム」App で HomePod をそのネットワークに移してください。2026-10-10 に壁が薄く近隣の Wi‑Fi が多い建物で、ルーターから 50 cm の HomePod を測定：2.4GHz 帯では ping の中央値 21 ms、p99 約 110 ms、損失 4% で、遅延 500 ms でも途切れました。5GHz 帯では 2 ms、最大 12 ms、損失なし。置き場所より効果があります。
5. HomePod の置き場所：ルーターを見通せる場所に置き、棚の中には入れないでください。
6. 遅延を 10〜15 ms 増やす：「シーン」で「カスタム」を選んで調整するか、ホーム ページに提案が出たら「適用」を押します。ホーム ページの「送信の状態」の下に直近 10 分間のネットワークの揺らぎの回数が表示され、余裕を食いつぶすほどになると、どちらの Wi‑Fi 区間が原因か（PC が有線 LAN なら必ず HomePod 側）、どの遅延にすればよいかを表示します。アプリが自分で遅延を変えることはありません。「音切れ」の欄はこの接続中の音切れの回数です：PC 側で実測したものに、余裕を食いつぶしたネットワークの揺らぎ（HomePod の音が途切れた可能性が高いもの）を加えます。HomePod は遅れて届いたパケットを報告しないため、後者は推定で、数字に「≈」が付きます。欄にマウスを置くと内訳が表示されます。

**ログの読み方**（`%APPDATA%\HomePodCast\homepodcast.log`、Microsoft Store 版は `%LOCALAPPDATA%\Packages\qiyinxi.HomePodCast_21rkx5qfj0b6t\LocalCache\Roaming\HomePodCast\homepodcast.log`。「設定 → ツール → ログ → ログ フォルダーを開く」で直接開けます）：送信中は 100 ms ごとに HomePod とルーターに ping を送り、往復が 30 ms を超えるか応答がないと `network: ping to the speaker took 48 ms`（ルーターは `the router`、応答なしは `lost`）と記録します。毎分の `stats:` 行には `rtx=再送/要求`、`rtxMiss=`（再送が間に合わなかったパケット）、`ping=中央値/p99/最大 lost=損失/送信 router=…` があります。

- スピーカーの ping だけが急増し、ルーターは正常：ルーター → HomePod の区間が原因です。4 と 5 を参照してください。
- 両方が同時に急増：PC 側の Wi‑Fi が原因です。1〜3 を参照してください。PC が有線 LAN なら原因はやはり HomePod 側の区間で（ルーターが自分宛ての ping に遅れて応答しただけ）、提案もそう表示します。
- ルーターだけが遅く、スピーカーは正常：ルーターは自分宛ての ping を後回しにすることが多く、音には影響しません。

## ビルド

.NET 10 SDK が必要です。

```
dotnet build src -c Release          # app\ に出力
dotnet test tests\HomePodCast.Tests  # プロトコル・音声・翻訳の単体テスト
```

MSI インストーラーは `installer\build.ps1` が WiX Toolset v5（ローカル dotnet ツール）でビルドします。詳しくは [installer/README.md](installer/README.md) を参照してください。

`tools\measure_av.py` はスマホで撮った動画から音と映像のずれを計算します。`tests\vectors\gen_vectors.py` は pyatv が使っている srptools でペアリング アルゴリズムの照合用データを生成します。

UI の文字列は簡体字中国語で `L.T("…")` / `L.F("…{0}", x)` の中に書き、訳文は `src/i18n/<言語>.json` に置きます（ファイルごとに 1 つの表示言語で、`en.json` が基準）。訳が抜けていたり `en.json` と一致しなかったりすると単体テストが失敗します。ブラウザー拡張機能の文字列は `extension/_locales` にあります。

## ブランチとリリース

| ブランチ／タグ | 用途 | ルール |
| --- | --- | --- |
| `dev` | 日々の開発 | プッシュのたびに CI が走り、プレビュー パッケージを作成 |
| `main` | 実機の HomePod で検証済みのコード | `dev` または `release/X.Y.Z` ブランチからの PR のみ受け付け、CI の成功が必須 |
| `vX.Y.Z` タグ | 正式リリース | `main` に付け、自動でビルドして GitHub Release を公開 |
| `release/x.y` | 旧バージョンの修正 | 必要なときだけ該当タグから作成 |

CI からは HomePod に接続できないため、`dev` を `main` にマージする前に実機で音ズレ測定を行います。

リリースの手順（ベータ版、テスト済みベータ版の正式版への昇格、公開前に CI が確認すること）は [docs/RELEASING.md](docs/RELEASING.md)（英語と簡体字中国語）を参照してください。

## コード署名

現在の配布ファイルにはまだデジタル署名がないため、インストーラーや exe を初めて実行するときに Windows SmartScreen の警告が出ることがあります（「詳細情報」→「実行」）。配布ファイルはすべて、このリポジトリの公開ソースコードから GitHub Actions で自動ビルドしています。[Releases](https://github.com/qiyinxi/HomePodCast/releases) ページからのみダウンロードしてください。

## プライバシー ポリシー

利用者が明示的に求めない限り、HomePodCast がほかのネットワーク上のシステムに情報を送ることはありません。通信するのは、利用者がローカル ネットワーク上で選んだ AirPlay スピーカーだけです。データの収集やアップロードは一切行わず、状態確認用のエンドポイントは 127.0.0.1 でのみ待ち受けます。ローカル ネットワークの外へ送る唯一のリクエストは更新の確認（[アップデート](#アップデート)を参照）で、「更新を確認」を押したときか、自動確認をオンにしたときだけ送ります。正式な内容は英語版をご覧ください：[Privacy policy](README.md#privacy-policy)。
