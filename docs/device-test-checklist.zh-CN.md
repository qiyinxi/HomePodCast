## 二、长时间游戏

- [ ] 「游戏」场景玩 30 分钟：有没有断音、爆音、卡顿？结束后把 `%APPDATA%\HomePodCast\homepodcast.log` 发我
- [ ] 中途切到「音乐」再切回来：重连约 1 秒，有没有异常

## 三、按键与托盘

- [ ] 把 Windows 设为**静音**，按键盘音量 +/−、静音键：HomePod 音量跟着变，Windows 保持静音
- [ ] 快捷键 Ctrl+Alt+PageUp / PageDown / Insert / N 各按一次
- [ ] 右键托盘图标：面板贴着图标弹出；拖音量、切场景、开关夜间模式；再右键一次能关掉
- [ ] 左键托盘图标打开主窗口

## 四、夜间模式与均衡

- [ ] 夜间模式开/关：爆炸、枪声变小，对白、脚步更清楚；低音减弱
- [ ] 麦克风与音效 → HomePod 输出均衡：「低音增强」「人声增强」听得出区别

## 五、浏览器插件（Chrome 或 Edge）

安装：解压 `HomePodCast-extension-*.zip` → 扩展程序页 → 开启开发者模式 → 加载已解压的扩展程序。

- [ ] YouTube 一个有人说话的视频：口型和声音对得上吗？插件弹窗显示的延迟是多少
- [ ] bilibili 普通视频、番剧各一个
- [ ] 暂停、拖进度条、全屏、网页全屏：画面有没有错乱
- [ ] 断开 HomePod 后：画面恢复不延迟

## 六、影视场景（播放器自动对齐，完成后再测）

- [ ] mpv / VLC 按设置页的说明开启控制接口后：切到「影视」，播放器的音频延迟自动设好；切回别的场景自动恢复
- [ ] PotPlayer：首页显示要手动填的数值，按它设置后口型对得上

## 七、安装包（MSI）

- [ ] 安装时可以改目录，默认 `C:\Program Files\HomePodCast\`；只弹一次 UAC
- [ ] 装完第一次启动：**不再**弹防火墙提示，能直接连上
- [ ] 卸载后：程序、快捷方式、防火墙规则都没了；`%APPDATA%\HomePodCast` 里的设置还在
